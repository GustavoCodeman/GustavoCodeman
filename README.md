# Gustavo Lopes

**Desenvolvedor Backend Python | SQL, APIs e Integração de Dados**

Desenvolvo APIs e soluções para integrar, validar e disponibilizar dados.

Minha experiência combina desenvolvimento backend com FastAPI e SQL com a atuação em sistemas de informação ambiental no Centro de Referência em Informação Ambiental (CRIA). Trabalho com dados científicos, processos ETL e suporte à rede speciesLink, conectando bancos relacionais heterogêneos à padronização de dados biológicos.

Também desenvolvi o Boreal Core, um sistema interno para automatizar processos de Segurança e Saúde no Trabalho, com APIs REST, modelagem de banco de dados e testes automatizados.

## Experiência em destaque

### CRIA · Dados científicos e speciesLink

Trajetória desde 2019, com atuação em suporte de sistemas, integração e qualidade de dados ambientais.

- Mapeamento e modelagem de bases relacionais heterogêneas para padronização de dados biológicos.
- Processos de extração, transformação e carga (ETL), validação e homologação de dados.
- Monitoramento de rotinas de indexação e correção de falhas em pipelines.
- Suporte e manutenção da rede speciesLink e apoio à publicação de dados científicos.
- Atendimento a instituições parceiras e colaboração com pesquisadores e equipes multidisciplinares.

### Boreal Core · Desenvolvimento Backend

Projeto freelance para a Boreal ENGMED, realizado entre março e agosto de 2025.

Sistema interno voltado à automação de processos de Segurança e Saúde no Trabalho, ao gerenciamento de projetos e à digitalização de relatórios e documentos técnicos.

- Desenvolvimento de APIs REST com FastAPI e Pydantic.
- Modelagem e implementação do banco de dados com SQLAlchemy.
- Implementação de testes automatizados com TDD.
